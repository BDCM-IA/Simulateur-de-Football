ESPACE PERSONNEL

Mon compte

Prépare la connexion à un compte permanent.

Connexion sécurisée

Cette version sauvegarde tes données sur cet appareil. Les comptes permanents entre plusieurs appareils nécessitent un service d'authentification et une base de données en ligne.

N'utilise jamais une clé secrète « service_role » dans ce fichier. Configure aussi les règles d'accès de la base de données avant d'y stocker des données personnelles.

Aucun compte en ligne connecté.

Ce qui est nécessaire pour activer les comptes

1. Créer un projet Supabase et activer l'authentification par e-mail.

2. Créer une table de profils et de données avec des règles RLS pour que chaque utilisateur n'accède qu'à ses propres données.

3. Ajouter l'URL du projet et sa clé publique ci-contre.

4. Configurer les URL de redirection de connexion pour ton site GitHub Pages.

5. Dans Supabase > SQL Editor, exécuter le SQL de création de la table teams et des règles RLS fourni avec les instructions sous le fichier.

Cette page ne déclare pas un compte « permanent » tant que le backend n'a pas été configuré et testé. La sauvegarde locale fonctionne indépendamment.
